# MultiCustomDictionary 自定义词典格式说明

> 源码：`headless/chat/src/main/java/com/tencent/supersonic/headless/chat/knowledge/MultiCustomDictionary.java`
> 继承：`DynamicCustomDictionary`（HanLP）

SuperSonic 基于 HanLP 的自定义词典做 Schema 元素识别。`MultiCustomDictionary` 扩展了原生 HanLP 词典，支持**多词性 / 多频率 / 原形（originals）** 的词条，并按业务把“词性”编码进 `nature` 字段，使分词结果能直接反查到对应的指标 / 维度 / 数据集 ID。

---

## 一、词典文件类型与分隔符

词典文件由 `MultiCustomDictionary.load()` 逐行解析：

| 文件后缀 | 分隔符 | 说明 |
|----------|--------|------|
| `.txt`（默认） | 空白字符 `\\s`（空格 / 制表符） | 标准文本词典 |
| `.csv` | 逗号 `,` | CSV 词典 |

加载时：
- 第一行若带 UTF-8 BOM 会被去除。
- 行内的制表符 `\t` 会被替换为空（再按分隔符切分）。
- 首列为空的行会被跳过（直到 `param[0].length() != 0`）。
- 文件名若含空格（如 `CustomDictionary 自定义词性.txt`），空格后的部分会被当作**默认词性** `defaultNature`，文件路径取空格前部分。

---

## 二、单行格式

### 2.1 基本格式

```
<word> [<nature> <frequency>]...
```

- `word`：词条文本（必填，第 1 列）。
- `nature`：HanLP 词性标识（可重复，成对出现）。
- `frequency`：该词性的词频（整数，与 nature 成对）。

### 2.2 词性数量计算

源码中：

```java
int natureCount = (param.length - 1) / 2;
```

即除 `word` 外，剩余字段按 `nature frequency` 两两分组：

| param 长度 | natureCount | 含义 |
|------------|-------------|------|
| 1 | 0 | 只有 word，使用 `defaultNature`（默认 `Nature.n`） |
| 3 | 1 | 单词性：`word nature freq` |
| 5 | 2 | 双词性：`word nature1 freq1 nature2 freq2` |
| 2N+1 | N | N 词性 |

### 2.3 示例

```
销售额 _10_101_metric 100000
PV _10_102_metric 100000 _10_103_metric 100000
北京 _10_201 8000
```

## 三、`nature` 词性编码规则（核心）

SuperSonic 把业务 ID 编码进 nature 字符串，分隔符为下划线 `_`（`DictWordType.NATURE_SPILT = "_"`）。
真正的“元素类型”以**后缀**形式附加在 nature 末尾。

`DictWordType` 定义的元素类型后缀：

| 后缀 | 枚举 | 含义 |
|------|------|------|
| `metric` | METRIC | 指标 |
| `dimension` | DIMENSION | 维度 |
| `value`（隐式，无后缀） | VALUE | 维度值 / 枚举值 |
| `dataSet`（隐式，无后缀） | DATASET | 数据集名 |
| `suffix` | SUFFIX | 反向词（用于后缀匹配，前缀加 `suffix`） |
| `term` | TERM | 业务术语 |
| `tag` | TAG | 标签 |

各类型 nature 编码格式（来自对应 `*WordBuilder`）：

| 元素类型 | nature 格式 | 来源 Builder |
|----------|-------------|--------------|
| **数据集** | `_<dataSetId>` | DataSetWordBuilder |
| **指标** | `_<modelId>_<elementId>_metric` | MetricWordBuilder |
| **维度** | `_<modelId>_<elementId>_dimension` | DimensionWordBuilder |
| **维度值** | `_<modelId>_<elementId>` | ValueWordBuilder |
| **业务术语** | `_<dataSetId>_<elementId>_term` | TermWordBuilder |
| **指标（反向/后缀）** | `_<modelId>_<elementId>_suffix_metric` | MetricWordBuilder(isSuffix) |
| **维度（反向/后缀）** | `_<modelId>_<elementId>_suffix_dimension` | DimensionWordBuilder(isSuffix) |
| **术语（反向/后缀）** | `_<dataSetId>_<elementId>_suffix_term` | TermWordBuilder(isSuffix) |

> 维度值（VALUE）类型没有显式后缀，其 nature 形如 `_<modelId>_<elementId>`。
> `DictWordType.getNatureType()` 判定逻辑：`length==3` 且第 2、3 段为数字 → VALUE；`length==2` 且第 2 段为数字 → DATASET。

### 3.1 词性解析示例

| nature 字符串 | 解析结果 |
|---------------|----------|
| `_10` | DATASET，dataSetId=10 |
| `_10_101_metric` | METRIC，modelId=10，elementId=101 |
| `_10_201_dimension` | DIMENSION，modelId=10，elementId=201 |
| `_10_201` | VALUE，modelId=10，elementId=201（维度 201 的枚举值） |
| `_10_201_suffix_dimension` | DIMENSION 反向词，modelId=10，elementId=201 |
| `_10_301_term` | TERM，dataSetId=10，elementId=301 |

## 四、词频

| 场景 | 词频取值 | 来源 |
|------|----------|------|
| 指标 / 维度 / 术语 / 数据集（名称词条） | `100000`（`BaseWordBuilder.DEFAULT_FREQUENCY`，等同 `Constants.DEFAULT_FREQUENCY`） | 各 WordBuilder |
| 维度值 / 枚举值 | 按指标聚合计算得来（`Math.round(metric)`），白名单值为 `itemValueWhiteFrequency` | DictUtils.fetchItemValue |
| 默认（无 nature） | `Nature.n` 默认词性，频率取 `defaultNature` 默认 | MultiCustomDictionary.load |

## 五、含空格的词与大小写处理

### 5.1 空格占位符 `#`

词条中若含空格，写入前会把空格替换为 `#`（`HanlpHelper.SPACE_SPILT = "#"`）。
加载时 `getWordBySpace()` 再把 `#` 还原回空格。

```
# 错误：含空格
New York _10_201 8000
# 正确：空格用 # 占位
New#York _10_201 8000
```

> 维度值写入时同样用 `#` 替换空格（`DictUtils.constructDictLines` 中 `value.replace(SPACE, POUND)`）。

### 5.2 字母词原形（originals）

当 `word` 为**含大写字母的字母串**（`isLetters` 判定：长度>1 且含 A-Z）时：

- `original` = 原始大写形式（如 `GMV`）。
- 词本身以小写形式入 Trie（`insert` 中 `word = word.toLowerCase()`；`load` 中通过别名词典补充小写别名）。
- `attribute.originals[i]` 记录原形，供 `transLetterOriginal()` 在 Embedding/HanLP 匹配后把小写名还原为原始名。

这意味着：**字母类指标名（如 GMV、PV、UV）会同时以小写形式入词典，并保留大写原形用于回写**。

### 5.3 别名（alias）

`BaseWordWithAliasBuilder` 会为元素的别名也生成词条（与正名共享同一 nature）。
字母词的大写→小写别名还会进入 `KnowledgeBaseService.dimValueAliasMap`（仅对维度值，nature 末段为数字 dimId 时）。

## 六、重复词条合并

`removeDuplicates = true`（默认）时，若同一 `word` 已存在，调用 `DictionaryAttributeUtil.getAttribute(旧, 新)` 合并：

- 多个 nature 会合并到同一 `Attribute`。
- `insert()` 运行时新增词条同样走合并逻辑（DAT 命中则 `dat.set`，否则写入 `trie`）。

---

## 七、运行时写入 vs 文件持久化

| 途径 | 作用 |
|------|------|
| `DictTaskServiceImpl.runDictTask` → `FileHandler.writeFile` | 把维度值查询结果写成 `.txt` 文件（行格式 `value nature frequency`） |
| `KnowledgeBaseService.updateSemanticKnowledge` → `HanlpHelper.addToCustomDictionary` → `insert` | 直接把 `DictWord` 插入内存词典（DAT/BinTrie），不落盘 |
| `MultiCustomDictionary.load` | 启动 / reload 时从 `.txt` 或 `.bin` 加载到内存 |

文件名规则（维度值文件）：`dic_value_<modelId>_<type>_<itemId>.txt`（见 `getDictValuePageFromFile`）。

---

## 八、加载与缓存

1. `load(path...)` → `loadMainDictionary(path[0])`。
2. 优先读 `path + ".bin"`（DAT 二进制缓存）；缓存不存在或过期则重新从文本加载。
3. 文本加载后构建 `DoubleArrayTrie`，并把 `customNatureCollector`、`Attribute` 列表、DAT 序列化为 `.bin`。
4. `reload()`：删除 `.bin` → 尝试读新缓存 → 失败则重新 `loadMainDictionary`。
5. 加载时同步维护 `NATURE_TO_VALUES`：以 nature 为 key，维护一个按词频降序、容量 `MAX_SIZE=10` 的 `PriorityBlockingQueue<Term>`，用于快速取该 nature 下高频词。

## 九、格式速查表

```
# 单词性
<word> <nature> <frequency>

# 多词性
<word> <nature1> <freq1> <nature2> <freq2> ...

# 无 nature（用文件名中的默认词性）
<word>

# nature 编码
dataSet   : _<dataSetId>
metric    : _<modelId>_<elementId>_metric
dimension : _<modelId>_<elementId>_dimension
value     : _<modelId>_<elementId>
term      : _<dataSetId>_<elementId>_term
suffix变体: _<modelId>_<elementId>_suffix_<type>

# 空格用 # 占位，字母词大写保留为 original
```
